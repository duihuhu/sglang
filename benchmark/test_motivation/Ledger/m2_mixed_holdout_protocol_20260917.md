# M2：Mixed 与冻结原生控制的迁移筛选

2026-09-17，执行前冻结。第一道门槛是已有控制之外是否还有机会，不是证明 hybrid 特有性。旧 Separate 结果不并入新配对。

## 范围与假设

模型 Kimi-Linear-48B-A3B、TP2，选空闲 GPU4/5。仅 Mixed4K，统一 raw 池 19481072000 bytes/rank，bootstrap state/request607、KV 参数781725，max-prefill-tokens16384。正确 slot 门限、token-VTC input1/output2/request0，无 prefix/radix/graphs/spec。保持算子、dtype、allocator、生产源码不变。

四个预先固定的策略：Native607；普通 runtime Cap512；原生 Slots96（runtime607）；诊断 Decode32（runtime607、最多延后32次新prefill扫描，不打断已有chunk）。沿用此前已验证参数，不按本轮性能调整。它们是有限的原生控制组，不是完整参数搜索或全部 SOTA。诊断策略使用请求组标签，不是可部署算法。

训练形态 train512：512个P512/O128背景。未参与此前阈值调参的 hold384：384个P1024/O128背景。两者候选均64个P8192/O64，组内1ms到达。不能比较两形态绝对延迟来归因state：输入量、并发和计算都不同。本轮测试的是固定控制规则的迁移，不把新随机种子当held-out。

## 时刻校准与正式矩阵

先在 Native607/Mixed 下对两种背景分别做两个独立启动的背景单独运行（rep71/72），每次完整预热。far/near到达锚点分别取第16/96个输出token的请求中位时间，再对两轮取均值。时刻校准不包含候选策略性能比较，不选择延迟更好的到达时刻。每个锚点核验至少80%背景存活、95%已输出，far剩余中位数>=80、near在16至48，state主体占live state+KV主体至少2/3。若校准不成立，停止并记录，不调到达点寻找收益。

随后冻结两种形态的到达计划、源码哈希、GPU身份。正式rep81/82，每个策略×形态×far/near各两次，共32组、16384请求，另32组完整预热同量排除。每个rep三个服务会话：无延迟会话内交错Native607/Cap512，Slots96与Decode32各独立会话；第二rep反转会话和case顺序。所有正式运行和预热都保留，即使到达场景不匹配也保留并标记该格不能作near/far归因，不按延迟排除样本。

单次完整性失败（请求/trace/连接/迟到/健康/释放）停止，不自动补跑；没有完整矩阵不报告完成。恢复必须另立计划。只锁定所选两张卡、两次idle检查、只清理自己的服务；不修改时钟或功率。

## 判据与边界

主目标沿用平均JCT降低，整体p95及makespan各退化不超过5%；新请求mean/p95 TTFT和JCT必须单列，这不是TTFT或公平保证。两次仅探索性，不给总体精确CI。

分别比较每个原生控制相对Native607，以及Decode32相对三个原生点。每个对照要求payload与到达计划相同，报告逐rep和是否真实触发；未触发时数值差不归因策略。若诊断不能在有效匹配场景下优于已测原生点，不能声称本动作见证了剩余缺口；这也不证明不存在任何更优动作。

配对场景额外要求到达时背景存活数相同，剩余输出中位数相差不超过8；不匹配的正式数值仍报告，不用于阶段归因或正收益判定。该门槛在采集前固定。

train512上的基线选择仅使用两个phase、两个rep：候选Cap512/Slots96必须每格通过原约束，否则回退Native607；合格者按相对Native607的平均JCT比率的几何均值选择，固定排序打破完全相同值。然后原样报告hold384中的所选策略，不用held-out重新选最优。保留其他原生点，避免只展示弱基线。

还记录实际peak active、slot delay、request-limit、NO_TOKEN、候选prefill与已有decode共批、释放时间和state-time。现有资源记录的NO_TOKEN为聚合路径，不足以独立区分state共享字节、KV预留与其他token预算；本轮不把它自动解释为state不足。只有确认剩余机会，后续才补逐候选字节/预算审计和三阶段探针，检验持续占用是否真的阻塞后续服务。

即使Mixed/held-out出现收益，也只是进入资源因果验证的依据。当前一active请求一state，逻辑state上限与普通cap等价；不能用该数量干预代替独立state成本消融。多模型、先进策略、生产graphs与稳态SLO不在本轮。
